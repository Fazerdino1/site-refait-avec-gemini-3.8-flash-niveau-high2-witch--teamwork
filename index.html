Build the perfect tools.

Our extension API is designed to allow anyone with web development skills to unleash the power of Raycast.

1. Cross-platform

Build your extension once using modern TypeScript and make it available to Raycast users on both macOS and Windows.

2. Built-in UI Components

Our React UI component library allows you to concentrate on business logic while Raycast renders pixel-perfect native layouts.

3. Batteries Included

A strongly typed API, hot-reloading in development, and modern tooling make writing extensions an absolute joy.

4. Publish to the Store

Submit your extension to the Raycast Store with a single command and share it with thousands of productive users worldwide.

import { List, ActionPanel, Action } from "@raycast/api";

export default function Command() {
  return (
    <List isLoading={false} searchBarPlaceholder="Search issues...">
      <List.Item
        title="Fix race condition in auth token"
        subtitle="RAY-1042"
        actions={
          <ActionPanel>
            <Action.CopyToClipboard content="RAY-1042" />
            <Action.OpenInBrowser url="https://linear.app" />
          </ActionPanel>
        }
      />
    </List>
  );
}
